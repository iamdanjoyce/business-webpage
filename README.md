# Dan Joyce Web Design

Website for Dan Joyce Web Design, served by GitHub Pages at https://iamdanjoyce.com.

## Layout

| Path | Purpose |
| --- | --- |
| `docs/index.html` | Coming-soon page (the live home page for now) |
| `docs/preview/index.html` | Full site, in progress at `/preview/` (not indexed by search engines) |
| `docs/content/settings.json` | Site text and pricing, edited through the CMS |
| `docs/admin/` | Decap CMS editor (`/admin` on the live site) |
| `docs/brand/` | Logo files: full lockup, compact, pin mark, app icon, favicon (light and dark versions) |
| `docs/brand/social/` | Social media PNGs: profile picture, link-share image, Facebook, LinkedIn and X banners |
| `docs/CNAME` | Custom domain for GitHub Pages |

## Editing

Edit text and pricing at https://iamdanjoyce.com/admin, or change the files in `docs/` directly.
Pushing to `main` publishes the site.
